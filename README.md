# van-build — CAD-каркас салона RAM ProMaster 1500 136" High Roof

Параметрическая **каркасная** модель салона кемпера на базе RAM ProMaster 1500
(колёсная база 136", высокая крыша; кузовной близнец — Fiat Ducato L2H2), построенная
во FreeCAD по 3D-скану реального кузова.

## Подход

- **CAD = только каркас** (к нему крепится оборудование). Обшивку в CAD не моделируем.
- **Обшивка = сам 3D-скан** кузова (меш), полупрозрачный, лежит поверх каркаса.
- Внутренний объём — не «коробка», а **сложная форма, снятая со скана**: гнутые борта,
  скруглённое плечо, округлая крыша. Рёбра каркаса — гнутые обручи по контуру скана.

Так совмещаются визуальное сходство (скан) и проектопригодная CAD-геометрия (каркас).

## Система координат

Ноль — пол у порога **задних** дверей, на центральной оси.
`X` = длина (0 сзади, +X к кабине); `Y` = ширина (0 центр); `Z` = высота (0 пол).

СК правая, как во FreeCAD: если смотреть вперёд на кабину, **+Y = левый борт (водитель)**,
**−Y = правый борт (пассажир, сдвижная дверь)**. В виде FreeCAD «Изометрия» ближний к тебе борт — это −Y.

## Сборка

Headless (быстро, но **без цветов** — в `van_v0.FCStd` не попадёт `GuiDocument.xml`):

```bash
~/Applications/FreeCAD.AppImage --console ~/van-build/van_v0.py
```

С цветами + картинки для проверки (открывает окно FreeCAD, сам закрывается):

```bash
~/Applications/FreeCAD.AppImage ~/van-build/tools/render_views.py
```

Картинки — в `renders/` (папка в `.gitignore`). На сервере без экрана — то же через
`xvfb-run -a -s "-screen 0 1920x1200x24"`.

Все рисунки проекта (чертежи и виды, которые хранятся в git) — одной командой:

```bash
FREECADCMD="$HOME/Applications/FreeCAD.AppImage --console" FREECAD="$HOME/Applications/FreeCAD.AppImage" tools/make_docs.sh
```

Скрипт измеряет профиль борта из `Ducato_L2H2_body_reference.stl`, строит каркас,
кладёт скан как обшивку и сохраняет `van_v0.FCStd` рядом с собой.

Коммитить `van_v0.FCStd` лучше собранный с цветами (`render_views.py`).
Источник правды — `van_v0.py`: геометрию руками в GUI не правим, `.FCStd` git не мёржит.

## Статус

Габариты оболочки и форма свода **измерены по скану**. Точные позиции рёбер, проёмов
дверей и колёсных арок — пока SEED-заглушки; заменяются на реальные значения
после ручного промера фургона (см. раздел про промерку в `PROJECT_MEMORY.md`).

Сторона сдвижной двери задаётся параметром `slider_side` в `van_v0.py`
(`-1` = правый/passenger борт `-Y` — так у этого фургона; `+1` = левый/driver борт `+Y`); текущая
оценка проёма — `1250 × 1755 мм`.

Текущая модель использует 3 основных гнутых обруча: задняя рама, смещённая внутрь обшивки на X=160, задняя/средняя
рама сдвижной двери и передняя рама сдвижной двери у кабины (`X=1880..3130`, по STL-окну сдвижной двери). Обручи красные,
продольные рейки синие; задняя распашная дверь показана двумя половинками.

Продольные рейки: верхняя поднята до `Z=1700`, средняя оставлена `Z=980`; нижняя `Z=20` показана как низовая крепёжная рейка, касающаяся пола (`Z=0..40`) и разрывается на зоне колёсных арок `X≈520..1650` и сдвижной двери.
Заводские резьбовые точки показаны отдельным слоем `FactoryThreadedMounts`: 3 точки на длинной `pY` рейке `Z=980`, 2 точки на короткой `nY` рейке `Z=980`; текущая память о резьбе — `M8/M10`, надо уточнить промером.

Поперечины пола удалены: в модели вместо них показан рефлёный металлический пол
`CorrugatedFloor` с продольными гребнями вдоль фургона.
